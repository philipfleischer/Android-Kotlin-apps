# Android-Kotlin-apps

## This repository contains a collection of Android applications developed in Kotlin throughout the semester.

### The purpose of this repository is:
- Structured practice in Android development
- Coursework for IN2000
- Experimentation with UI, architecture, and Android components
- Gradual portfolio building over time

The repository will continuously expand as new applications are developed.

⸻

### Purpose of This Repository

This is a portfolio-oriented repository designed to demonstrate:
- Android fundamentals
- Kotlin proficiency
- Navigation and multi-screen apps
- UI/UX experimentation
- API integration
- Splash screen configuration
- Incremental improvement over time

Each app is self-contained and represents a focused learning objective.

### Structure

Each application lives in its own directory and contains:
- Gradle configuration
- AndroidManifest configuration
- Theming setup
- Kotlin source files
- Resource files

This ensures each app is isolated and reproducible.

⸻

### Development Philosophy

This repository follows a structured learning approach:
1. Build small focused apps
2. Understand one concept deeply at a time
3. Refactor when necessary
4. Document implementation decisions
5. Improve architectural quality gradually

The goal is not just to complete assignments, but to build production-level understanding over time.
