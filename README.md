# Android-Kotlin-apps

## This repository contains a collection of Android applications developed in Kotlin throughout the semester.

This repository contains several small self-contained projects. Each app focuses on a specific Android concept or learning goal.

⸻

### Purpose

The purpose of this repository is to document my progression in Android development with Kotlin.

The repository is used for:

- Android and Kotlin practice
- IN2000 coursework
- UI and navigation experiments
- API integration practice
- Local database and persistence practice
- Architecture and dependency injection practice
- Unit testing and exam preparation
- Portfolio documentation
